# Synthetic fixture provenance

`sample.csv` is generated by `src/data.py:sample`, authored for this application on 2026-09-16. All prices, volumes and instrument names are invented; no market dataset was copied or licensed. There is no random number generator, so no seed is required. Three explicitly scheduled sessions contain DEMO-WIN, DEMO-LOSS and DEMO-SKIP. The names expose their software-test purpose.

Day two contains a qualifying breakout/volume pulse, a subsequent entry observation, a target-reaching bar and an adverse stop gap. DEMO-SKIP lacks a volume pulse. Rules and mock automatic policies execute one winner and one loser, resulting in INR -5.12 after estimated costs. This chosen fixture distribution has no inferential relationship to NSE performance.

`invalid.csv` is a deliberately invalid OHLC example for the importer. Select `mock_fail` in new-run settings to demonstrate an AI timeout without network access. Approval expiry, rejection, missing bars and malformed AI are covered by tests. Regenerate sample and reports with `python -m src.cli --db data/verification.db demo-report` using the project Python environment.

`research-example.json` is also invented, with an example.com URL. It tests publication/availability filtering and must not be presented as real company news. It introduces no external data dependency or network request.
